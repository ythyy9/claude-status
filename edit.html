正在连接 GitHub…

先填一次 GitHub 令牌

保存时要把修改写进 GitHub 仓库，所以需要一个只能改这个网站的令牌。令牌只存在这台设备的浏览器里。

  1. 打开 GitHub 新建令牌页面（Fine-grained token）
  2. Token name 随便填，Expiration 选一个有效期
  3. Repository access 选 Only select repositories，再选 ythyy9/claude-status
  4. Permissions 里点 Add permissions，选 Contents，权限改成 Read and write
  5. 点 Generate token，复制以 github_pat_ 开头的令牌，粘贴到下面

改完点底部的“保存”，大约 1 分钟后页面更新。
